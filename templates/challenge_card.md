## Решение

**COMMIT принят в ______ (время от T0).**

**Фальсификатор — переходим к следующему кандидату, если:** ______

**Точка обязательства: ориентировочно T0 + 3 часа.** После неё сравнение прекращается. Смена направления возможна только при жёстком блокере — отметить, какой именно:

- [ ] обещанные данные недоступны
- [ ] требуемый API недоступен
- [ ] раскрылось неустранимое требование вне возможностей команды
- [ ] место в треке недоступно
- [ ] критическая доменная зависимость
- [ ] основной результат невозможно оценить

«Другая задача интереснее» блокером не является.
