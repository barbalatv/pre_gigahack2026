### Рабочий путь каталога госуслуг

1. Получить категории.
2. Выбрать актуальный id из ответа: проверенная категория «Inițierea unei afaceri» — [category detail](https://servicii.gov.md/rsspa-api/catalog/categories/10570ad9-0de6-43b1-a813-b14e6198fac8).
3. Из publicServices взять актуальный code и запросить detail: [001000056](https://servicii.gov.md/rsspa-api/public-service/code/001000056) вернул HTTP 200 с содержимым.

**OBSERVED PRACTICE:** старый код 006000022 из README победителя 2023 сейчас вернул HTTP 204 без тела. Это не означает, что весь API не работает. Сохранены sample responses в research/evidence. Для продукта обрабатывать отсутствующую услугу, пустой перевод, HTML в поле и дату источника. Не использовать один старый пример как единственный dataset.

### Как не ошибиться с CKAN

В проверенном ответе набор MinFin о резервном фонде имел неопределённую лицензию в metadata. У транспортного набора свежая дата изменения каталога соседствовала со старыми датами ресурсов и ссылкой на Statbank. **INFERENCE:** ни обновление карточки, ни нахождение в «open data» сами по себе не доказывают разрешённость и актуальность для вашего сценария.

Перед выбором набора получить сам файл, проверить период наблюдений, единицы, уровень агрегации, пропуски, права, owner и соответствие метрике. Для municipal operations годовая статистика может дать контекст проблемы, но не заменить обращения/диспетчерские события.

### Лицензии карт и погоды

Roataway infrastructure отдельно указывает ODbL для dataset и AGPLv3 для helper tools; не приписывать всем файлам MIT и не смешивать условия данных и кода. [LICENSE](https://github.com/roataway/infrastructure-data/blob/develop/LICENSE).

У Open-Meteo данные распространяются на условиях CC-BY 4.0, но бесплатный API ограничен некоммерческим использованием. Коммерческий пилот/продвижение нельзя автоматически считать покрытым этим доступом. [Terms](https://open-meteo.com/en/terms). Предварительный технический probe не подтверждает право использовать free endpoint для любого будущего продукта.

Если этого нет, предложить owner демонстрацию на согласованном export и явно описать будущую интеграцию. Если live integration обязательна по brief, её отсутствие — блокер, а не повод скрыть mock.

## 3. Где местное знание даёт преимущество

**Smart City:** знать, кто назначает исполнителя, меняет статус, принимает результат и отвечает за дубль обращения. У города уже есть EU.CHISINAU.MD и опубликованный регламент. [Муниципальный документ](https://preturabuiucani.md/wp-content/uploads/2025/03/EuChisinau_Regulament.pdf). Новый интерфейс подачи жалоб должен иметь обоснованное отличие или встраиваться в существующий процесс.

**Госуслуги:** корректно работать с RO/RU, диакритикой, названием органа, документом-основанием, сроком и версией источника. Отвечать «не найдено» лучше, чем выдумывать порядок получения услуги.

**Energy/AgriFood:** отличать мощность и энергию, период измерения и прогнозный горизонт, партии/SKU/сроки годности, агрегацию по объекту и по району. Доступность погоды и общей статистики не заменяет данных партнёра. Конкретный набор выбирать после brief.

**Medpark:** локальный медицинский workflow и валидатор под тип утверждения важнее общего medical chatbot; клиницист обязателен для клинического утверждения, для административного достаточно владельца процесса. Общедоступный разрешённый dataset пациентов Medpark не получен. До согласования использовать synthetic records для демонстрации пути; не заявлять клиническую точность.

**Cybersecurity:** SOC.MD 2026 — подготовленные range/IR навыки, а не просто генерация сканера ссылок по примеру 2025. Проверять только предоставленную организаторами область и правила действий.

## 4. Данные и закон к сентябрю 2026

**FACT:** CNPDCP сообщает о вступлении закона 195/2024 в силу **23 августа 2026**. Поэтому опора на прежний режим без проверки уже устарела к GigaHack. [CNPDCP](https://datepersonale.md/23-august-2026-un-nou-reper-pentru-protectia-datelor-cu-caracter-personal-in-republica-moldova/).

GDPR не применяется к каждому молдавскому prototype автоматически: важны условия его территориального охвата, включая деятельность в ЕС и определённые случаи предложения услуг/мониторинга людей в ЕС. [GDPR, статья 3](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng). Применимость к конкретному пилоту определяется его устройством; этот документ не устанавливает юридическое соответствие проекта.

**RECOMMENDATION для demo:** подготовить одностраничную карту данных: источник → поля → хранение → внешние сервисы → удаление → ответственный. Убрать ненужные идентификаторы, использовать согласованные synthetic/anonymized samples, серверные секреты и минимальные логи. Простое скрытие имени не гарантирует анонимность. Передача реальных записей в LLM требует согласованного основания и разрешённого маршрута, а не только API-ключа.

Не обещать «GDPR compliant» за наличие checkbox или шифрования. Для жюри сильнее точный ответ: какие данные использованы сейчас, какие риски исключены, что должен согласовать owner до настоящего пилота.

## 5. Что подготовить в один вечер

Скачать маленький разрешённый sample; записать URL, дату и лицензию; прочитать его двумя способами; проверить RO/RU и пустые поля; сохранить source-backed пример; показать действие пользователю; выполнить один отказ. Не тратить вечер на десяток непроверенных интеграций.
