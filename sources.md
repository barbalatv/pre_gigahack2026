# Источники и границы доказательств

**Все перечисленные проверки относятся к срезу 5 сентября 2026.** Дата ниже — дата публикации/версии, когда она установлена; «live» означает текущую страницу без надёжно установленной даты публикации. Таблицы связывают существенные claims с источниками. Полные ссылки также стоят рядом с утверждениями в документах.

Первичный официальный текст предпочтительнее пересказа. Participant post подтверждает рассказ участника, repository — доступные файлы, но не их исполнение на judging. HTTP 200 подтверждает ответ на конкретный запрос, а не SLA или разрешение на любое использование.

**Новые вводные 05.09:** [transcript](gigahack_official_assistant_transcript.md) предоставлен пользователем как карта leads; [operating decisions](operating_decisions.md) — источник внутренних решений, не официальных норм. Проверка leads — [operating alignment](research/operating_alignment.md).

**Смена baseline 05.09 (вечер):** переход на одну основную команду — внутреннее решение; источников оно не добавляет и не отменяет. Повторно проверена главная страница GigaHack (восемь карточек без изменений, participant rulebook не опубликован) и добавлен один новый первичный источник — страница проекта Technovator.

## Как обновлять пакет

Новая норма меняет canon только после появления источника. Новая гипотеза идёт в challenge/strategy с условием проверки. Новые числа качества в pitch появляются после измерения. Данные о недоступности сохраняются как наблюдение конкретной проверки, без утверждения «этого нигде нет».
